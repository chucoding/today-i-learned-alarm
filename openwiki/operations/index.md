# 파일

- [로컬 개발·검증·배포](local-development-and-deployment.md) - pnpm 워크스페이스에서 프런트엔드와 Firebase Cloud Functions를 설정·실행·검증·배포하는 절차를 설명한다. 환경 변수 생성, 워크트리별 Firebase 선택, Functions URL의 빌드 시점 계약과 Hosting 산출물 경계를 다룬다.
- [푸시 알림과 정기 정리 작업](push-notifications.md) - 브라우저의 FCM 등록과 사용자별 시간대·희망 시각 설정을 매시 Cloud Scheduler 발송으로 연결하는 운영 흐름을 설명한다. 탈퇴 기록의 당일 재가입 차단과 KST 기준 정리 수명도 함께 다룬다.
