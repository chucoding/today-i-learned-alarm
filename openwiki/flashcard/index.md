# 파일

- [일별 덱 크기 예산](deck-size-budget.md) - 한 날짜의 한국어·영어 플래시카드 덱을 하나의 Firestore 문서에 저장할 때 적용하는 직렬화 바이트 예산과 축소 계약을 설명한다. 앱과 Cloud Functions의 생성 경로, 이중 언어 병합, 큰 기존 덱의 한계를 함께 다룬다.
- [플래시카드 생성과 복구 경로](generation-paths.md) - 오늘의 언어별 덱을 우선 읽고 번역 또는 즉석 생성으로 복구하는 사용자 경로와, 사용자·랜딩 사전 생성 및 질문 재생성의 저장·실패 경계를 설명한다.
- [시간대별 덱 사전 생성](pregeneration.md) - 최근 활동 사용자의 로컬 자정 뒤에 스케줄러가 일별 플래시카드 덱 생성을 예약하는 비동기 워크플로다. 시간대·언어 동기화, 앱과의 저장 경쟁, 완료 기록 및 재시도 경계를 설명한다.
